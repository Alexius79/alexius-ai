# alexius.ai

Persönliche Landingpage von Alexander Hirsekorn.

- `index.html`, `style.css`, `app.js`: Seite und Animation (Canvas 2D, ohne Build-Schritt)
- `side.webp`, `front.webp`: freigestellte Porträts

Ablauf: Seitliches Porträt + Schriftzug „alexius.ai“ → Tippen → Schriftzug fliegt in die Brust,
das seitliche Porträt löst sich in Partikel auf und setzt sich frontal wieder zusammen.
